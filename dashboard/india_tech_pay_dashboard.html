Data & methodology. This sandbox has no live network access for a real-time Scrapy crawl, so the pipeline instead anchors a synthetic 12,000-posting generator to real 2026 India tech salary research (role/experience bands, company-type multipliers, city premiums, GenAI/MLOps/cloud skill premiums) gathered via web search, then trains real models on top of it: a Gradient Boosted Trees regressor (standing in for XGBoost, which couldn't be pip-installed offline) and a Ridge regression on log-salary whose coefficients power the live predictor above. Demand forecasting uses a per-role linear trend fit as a lightweight stand-in for Prophet.

Sources: Instahyre Resources · AmbitionBox/6figr via Simpliaxis · Jobkar · ProductLeadership.com (AI PM & Data Scientist guides) · Futurense · TheBusinessSalary.com · Masai School — all 2026 India tech compensation reports.
